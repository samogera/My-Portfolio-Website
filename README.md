# samogera-portfolio

Personal site of Samuel Ogera: founder of MatXchange and Aximo Hub, software engineer in Nairobi.

Live at https://ogera.is-a.dev

## Structure

- `index.html` — the site (Home, Work, About, Contact)
- `support.js` — runtime for the page
- `assets/` — logos, icons, CV, share image
- `robots.txt`, `sitemap.xml`, `llms.txt`, `humans.txt`, `site.webmanifest` — search and AI files
- `CNAME` — custom domain for GitHub Pages

## Deploy

Settings → Pages → Deploy from branch → `main` / root.
